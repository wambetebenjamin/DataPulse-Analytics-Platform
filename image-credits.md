# Image Credits

All photography on the DataPulse Analytics Platform is sourced from **Pexels**
and **Unsplash** under their respective free licences, saved locally, and
restricted to East African business settings. **No AI-generated imagery is used
anywhere on this site.**

---

## ⚠️ Current state of this file

The build environment this site was assembled in has **no network egress to
`images.pexels.com` or `images.unsplash.com`** (both resolve but refuse the
connection). Rather than ship photography from the wrong source — the available
image search returned Getty Images, 123RF and Vecteezy results, which are
licensed stock and explicitly outside the brief — the site currently renders
**committed branded SVG placeholders** built from the Soft UI design tokens.

Nothing is broken and nothing is mis-credited. To swap in the real photography,
run the fetcher from any machine with normal internet access:

```bash
# Pexels (free key: https://www.pexels.com/api/)
PEXELS_API_KEY=your_key node scripts/fetch-images.mjs

# or Unsplash (free key: https://unsplash.com/developers)
UNSPLASH_ACCESS_KEY=your_key node scripts/fetch-images.mjs --provider unsplash
```

The script downloads each photo to `public/images/**.jpg` and **regenerates
this file** with real attribution pulled straight from the provider API —
photographer name, profile URL, photo page URL and licence. No credit is ever
hand-written or invented.

`src/lib/images.ts` prefers `<slug>.jpg` when it exists and silently falls back
to `<slug>.svg` when it does not, so the swap needs no code change.
